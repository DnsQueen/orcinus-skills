- **Upstream bug found and fixed in the bundled copy (2026-11-06, from an external review):** `scripts/with_server.py` had four defects. (1) The server's stdout and stderr were piped but never read, so a log-heavy server blocked on the full pipe and its output was swallowed — the ORCINUS team hit this itself (the script once left a child server running and swallowed stdout). Fixed: both pipes are drained continuously in background threads and forwarded to this script's stdout/stderr. (2) Readiness was only "the port is open", which a different service on the same port can satisfy. Fixed: `--ready-path` (e.g. `/health`) does an HTTP GET and requires an HTTP response; while waiting, the script also checks that the server process is still alive. (3) Cleanup called `terminate()` on the shell process (`shell=True`), so the real server kept running. Fixed: each server starts in its own process group (`start_new_session=True` on POSIX) and cleanup signals the whole group (SIGTERM, then SIGKILL). (4) The test command had no timeout. Fixed: `--test-timeout` (default 300s). The fixes are covered by `scripts/test_with_server.py` (6 tests).
- **Scope note:** this skill tests local web applications with Playwright (Python) and needs a browser. Upstream says these skills are for demonstration/education and should be tested in the user's own environment before being relied on for critical work.
